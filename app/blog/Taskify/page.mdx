This project was my second time doing a full stack Svelte project, but the first time with a group of friends! As apart of our Web Programming class, we chose to do a full stack,
all-in-one planning application. It had so many different parts, with technologies like Svelte and Python to help with the frontend, and Docker, Dex, GoogleOAuth, and MongoDB to help
with the backend.
